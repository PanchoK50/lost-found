# Exterior textures

Generated by `tools/art/generate_exterior.py` (Gemini image generation on Vertex). All are 512×512 JPG.
Contact sheet with 2×2 tiled previews: `tools/art/out/exterior/contact.png`.

## Facades (wall textures)

Mapping convention: **U runs along the wall in metres, one repeat = one window bay ≈ 3 m**
(`repeat.x = wallLength / 3`). **V spans exactly one storey** (`repeat.y = storeyCount`, or
`wallHeight / storeyHeight`): image bottom = floor slab, image top = just under the next slab. Each
image shows the slab/spandrel band at the very bottom. They tile seamlessly left-right and stack
per storey. Use `RepeatWrapping` on both axes and `SRGBColorSpace`.

| File | What | Suggested use |
|---|---|---|
| `facade-office.jpg` | Curtain wall: light grey aluminium mullions, blue-grey glass with a faint sky reflection, spandrel panel at the bottom | Office buildings, upper storeys |
| `facade-ground-office.jpg` | Ground-floor variant of the office: taller glazing with a transom, no spandrel panel, base band only | Office ground floor (storey 0) |
| `facade-campus.jpg` | Light warm-grey render with one large punched window (dark glass, light frame), thin slab line | University / school / public buildings |
| `facade-brick.jpg` | Red-brown brick, white sash window with stone sill, light concrete slab band | Residential / older buildings |
| `facade-industrial.jpg` | Light grey corrugated metal cladding, high horizontal ribbon window, dark base band | Factory halls, warehouses, workshops |
| `facade-office-night.jpg` | Night version of the office: dim blue facade, warmly lit glass | Night or emergency mode |
| `facade-campus-night.jpg` | Night version of the campus: dim blue render, warmly lit windows | Night or emergency mode |

The night variants light every window (one bay per repeat). For "some windows lit", mix them with
the day texture per bay, or multiply them by a per-bay random factor in the shader.

## Top-down textures (tile in both directions)

| File | What | Suggested metres per repeat |
|---|---|---|
| `roof-flat.jpg` | Light grey gravel / membrane flat roof with faint seams | 6 m |
| `roof-green.jpg` | Extensive sedum green roof, muted greens with reddish patches | 4 m |
| `plinth.jpg` | Light stone paving slabs (about 4×4 slabs, mixed sizes) for the strip around buildings | 3 m |
| `ground-grass.jpg` | Mown lawn, soft green, faint mowing stripes | 6 m |
| `ground-asphalt.jpg` | Plain light grey asphalt, no markings | 5 m |
| `ground-pavement.jpg` | Light grey square concrete pavers (about 6×6) | 3 m (≈ 0.5 m pavers) |

Set `repeat = extent / metresPerRepeat` with world-space UVs (x, z in metres) so the scale stays the
same on every building. The textures are light and low in contrast, so they can also be multiplied
with a tint colour.

## Regenerating

    uv run tools/art/generate_exterior.py <gcp-project> [name ...]

Raw images are cached in `tools/art/out/exterior/<name>.png`. Delete one to regenerate it (about $0.05 each).
